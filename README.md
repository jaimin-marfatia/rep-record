# Rep & Record

Build a gym workout tracker for myself with the possibility of sharing with others.

Core requirements:
- Defined muscles to choose from: biceps, triceps, chest, shoulder, back, abs, and legs.
- Weight options: quick selector buttons starting from 10 lbs with increments of 5 lbs up to 60 lbs (10, 15, 20, 25, 30, 35, 40, 45, 50, 55, 60 lbs), with an option/input field to enter custom or higher weight amounts.
- Weight tracking model: total weight only.
- Workout logging: log workouts by selecting muscle, entering total weight and reps, with quick-save and viewing today's active session history.
- Visualizations & graphs: creative charts showing weight and volume trends over time per muscle group, a weekly muscle split radar/balance chart, and personal best PR milestones.
- Sharing: public shareable workout link or summary card that can be viewed by anyone without editing permissions.
- Clean, responsive mobile-friendly UI.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
